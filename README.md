This is a backend finance tracking application built using Go and PostgreSQL. (Just for practice)

## Features

- Add expenses through REST API
- Store expenses in PostgreSQL database
- JSON API responses
- Backend server built with Gin framework

## Technologies Used

- Go (Golang)
- Gin Web Framework
- PostgreSQL
- Git & GitHub

## Current Endpoints

### Add Expense

POST /add-expense

Example JSON:

{
  "category": "Food",
  "amount": 75
}
